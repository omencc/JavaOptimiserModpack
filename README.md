## ⚡ About

**Holy Optimized** is a simple Minecraft optimization modpack built to improve FPS, reduce lag, and make gameplay smoother without changing the vanilla feel.

Perfect for:
- 🖥️ Low-end PCs
- ⚔️ PvP
- 🌎 Multiplayer
- 🧱 Vanilla survival
- 🚀 Faster loading

---

## 🔧 Included Optimizations

- Sodium
- Lithium
- FerriteCore
- ImmediatelyFast
- Entity Culling
- ModernFix

And more lightweight performance improvements.

---

## 📈 Features

✔️ Higher FPS  
✔️ Reduced RAM usage  
✔️ Faster startup times  
✔️ Smoother chunk loading  
✔️ Cleaner gameplay experience  
✔️ Minimal & stable setup
